# AI 工具 · 外贸开发客户工作流

---

## 总览：AI在你工作中的位置

```
你 ← 负责判断、决策、建立关系
 │
 ├── AI → 写内容、做研究、处理数据
 ├── 工具 → 自动发送、跟踪、提醒
 └── CRM → 沉淀所有信息
```

**AI不替代你，AI让你每天多出3小时做真正的事：给客户打电话、视频验厂、建立信任。**

---

## 工作流一：客户研究（每天9:30-10:30）

### 场景：你找到一家潜在客户公司，需要了解他们

**传统方式：** 打开公司官网，手动看半小时，记笔记。

**AI方式（10分钟）：**

**Step 1: 用AI做公司画像**
```
在 ChatGPT / Claude / DeepSeek 中输入：

"帮我分析这家公司：[公司名]，网站是 [URL]。
请提取：
1. 公司主营业务和定位
2. 他们的目标客户是谁
3. 他们目前在卖什么型号的电笔/万用表
4. 他们的供应链可能存在什么问题（从交期、质量、价格角度推测）
5. 给我三个切入点——我写开发信时应该抓住什么"
```

**Step 2: 用AI找到关键联系人**
```
"这家公司可能负责采购电工仪表的人，职级头衔通常是什么？
在LinkedIn上用什么关键词能搜到他们？
给我10个搜索关键词组合。"
```

---

## 工作流二：开发信写作（每天10:30-11:30）

### 场景：你需要给10个不同客户写个性化开发信

**不要做的事：** 写一个模板，替换公司名，群发。

**AI方式（高效且个性化）：**

**Step 1: 先做客户研究（工作流一）**

**Step 2: 把研究结果喂给AI生成开发信**
```
"基于以下客户信息，帮我写一封开发信。

客户公司：[名字]
国家：[国家]
客户痛点推测：[他们的供应商交期太长，客户抱怨]
我的优势：月产50万台，15天出货，48小时打样，EMC/LVD/RoHS全系认证

要求：
- 不超过120个单词
- 用收件人的真名开头（我稍后填）
- 第一句必须提到他们公司/市场相关的具体信息
- 以一个问题结尾（不是推销句式）
- 语气专业但不僵硬
- 不要用'Dear Sir/Madam'
- 不要用'We are a leading manufacturer...'"
```

**Step 3: 人工检查+个性化微调（3分钟/封）**

**Step 4: 翻译成多语言（如果需要）**
```
"把上面这封开发信翻译成西班牙语，保持原文的专业语气和简洁风格。"
```

## 工作流三：独立站内容生产（每天下午2:00-3:00）

### 场景：为SEO产出Blog文章或产品描述

**产品页描述生成：**
```
"帮我写一个数字万用表的产品页面英文描述。

产品信息：
- 型号：ZY-830D
- 功能：AC/DC电压、电阻、二极管测试、通断蜂鸣
- 特点：自动量程、背光LCD、CAT III 600V安全等级
- 认证：CE EMC LVD RoHS
- 目标客户：工业电工、电气维护工程师

格式要求：
- 一句话标题（含关键词Digital Multimeter）
- 4个核心卖点（bullet points）
- 技术规格表格（Markdown格式）
- 一段FAQ（3个问题，含MOQ和交期）
- 全英文，自然SEO，不要堆砌关键词
- 字数：300-400 words"
```

**Blog文章生成（每月4篇）：**
```
"写一篇300-400词的英文Blog，主题：
'How to Choose a Digital Multimeter for Industrial Maintenance'

要求：
- 面向工业维护电工，非电子工程师
- 提及安全等级（CAT III vs CAT IV）
- 提及精度和可靠性对工作安全的影响
- 自然提到'buy from a certified manufacturer'
- 结尾引导读者联系供应商做定制需求
- SEO友好但不做作"
```

## 工作流四：客户跟进管理（每天下午3:00-4:00）

### 场景：CRM里一堆客户，不知道先跟谁

**AI方式：**

**用AI整理跟进优先级：**
```
"以下是我CRM中等待跟进的客户列表，帮我分析优先级：

[粘贴客户列表，格式：客户名 | 国家 | 上次联系日期 | 当前阶段 | 上次沟通摘要]

请帮我：
1. 按紧急程度排序（最该立刻联系的排最前）
2. 对每个客户给一句跟进建议（该说什么）
3. 标注哪些可能已经凉了（超过30天无回复且无实际进展的）"
```

**用AI生成跟进话术：**
```
"这个客户[客户名]在[国家]，一个月前要了报价但没回复。
上次报价：1000台 ZY-830D，单价$X，FOB温州。

帮我写一封跟进邮件/WhatsApp消息：
- 不催单，不提价格
- 提供一个有用的信息（比如：'我们刚通过了新版的LVD认证'）
- 结尾问一个开放式问题
- 不超过80个单词"
```

## AI使用铁律

1. **AI写的内容，你必须修改。** 做不到每封都读一遍，至少扫一眼。AI会编造不存在的事实。
2. **不要直接用AI翻译开发信发给德国客户。** 德语语法错误在母语者眼里像你收到一封"亲爱的客户，我们是专业厂家，产品很好，价格便宜"的中文——能懂，但不想回。
3. **AI做研究，你做判断。** AI说"这家公司可能有问题"——去验证。AI说"市场机会在这"——自己去看看。
4. **别把所有数据放进公共AI。** 客户的联系方式、报价细节，不要直接粘贴到免费ChatGPT里。用API模式或本地模型处理敏感信息。
